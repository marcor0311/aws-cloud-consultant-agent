# 3. Architecture Agent

**Responsabilidad:** Diseño de arquitectura.

Trabaja con el Cloud Solutions Architect en el repositorio del proyecto creado
desde el template. Recibe el issue y los insumos aprobados de dirección; prepara
requisitos, diseño AWS como código, ADRs, políticas y estimación inicial. Consulta
el catálogo de baselines y entrega el diseño aprobado a FinOps. El trabajo sobre
los módulos de baselines se realiza en su propio repositorio y sesión de Codex.

## Estado

Carpeta de organización; todavía no tiene runtime propio. El backend conserva
los contratos de la etapa en [workflow](../../backend/app/workflow/). La ejecución
de diseño, revisión y publicación de PRs sigue pendiente.

Contrato funcional: [issues.md](../../../issues.md#3-cloud-solutions-architect--diseño).
La numeración identifica al agente dentro del registro; no es un paquete Python.
