# Technology icons

Local presentation tiles use a 48 × 48 canvas, contrasting light or dark backgrounds and rounded corners
alongside Skill Icons in the root README. Logos retain their brand artwork;
monochrome paths use contrasting ink or their brand color. Tiles display at 56 px
with larger artwork and 5 px internal padding.

Sources:

- LangGraph, MCP, LiveKit, OpenAI, Claude, Claude Code, GitHub Copilot, Codex, Gemma and AssemblyAI:
  [Lobe Icons](https://github.com/lobehub/lobe-icons), MIT license.

  [Simple Icons](https://github.com/simple-icons/simple-icons), CC0.
